## 2.x 自用基线的真实验收

- 126 implicit TLS 465 收到 greeting，AUTH PLAIN 登录返回 235。
- 普通测试邮件和原创小 EPUB 被 SMTP 接收，返回 250。
- 用户确认小测试书可以在 Kindle 正常打开。
- 用户确认正式脚本安装运行后，网页推送可以同步。
- 一个 50 MB 人工压力文件到达 Amazon 后返回 E999，不能据此认定超限，也不能当作真实大书转换成功。

以上证明自用基线链路可行，不等于每个新账号、每种书籍页面、每台手机都已验证。

## 3.2.0 本地自动化与运行时检查

依赖已在独立检查目录中通过 npm 10.9.2 的 npm ci 安装。本版本完成 43 项自动测试，包括公开安装包的可重复构建、首次连接、URL 校验、换服务清除令牌和旧标签页保护；运行时集成和部署 dry-run 均通过。

- 鉴权、方法、HTTPS、非法文件名、大小声明、内容类型、ZIP 结构验证。
- SMTP 多行/分段回复、PLAIN/LOGIN、错误脱敏、SIZE 预检查、最终回执丢失和 QUIT 失败处理。
- 单对象串行、失败后解锁、50 MB 全量编码后解码哈希一致。
- 脚本先做服务检查、下载请求不附带令牌、Blob 上传、首次安装启用提示、无令牌提示。
- 动态服务域名安装脚本、setup/panel 兼容入口、配置提示和部署元数据检查。
- Miniflare/workerd 使用实际 SQLite Durable Object 绑定完成 50,000,000 字节上传、ZIP 检查和 MIME 编码。外部 SMTP 调用被测试替身代替，不发真实邮件。
- Wrangler dry-run 成功打包并识别 MAIL_SENDER 绑定。

另完成隔离的 headless Chromium 页面测试：使用真实构建页面及 CSP、模拟 GM 私有存储与 HTTP 回复，检查无脚本状态、安装响应、复制备用路径、401/535 错误、成功保存/清空、HTTPS 站点启用和无 opener 新标签页；验证过程没有调用发信接口。电脑 1120px 和手机 390px 宽度逐步检查无横向溢出，并检查截图。

该界面测试不是安装真实 Violentmonkey，也不是 Windows/Android Firefox 真机验收；未访问真实书籍网站或发出新邮件。UI 模拟检查作为本次审阅记录，仓库中的可重复基础测试是 `npm test`、`test:runtime` 和 `check:deploy`。

3.2.0 另在 1120px/390px 宽度测试公开脚本：仓库连接栏实际 closed shadow DOM 的键盘输入与按钮操作、保存服务地址、清除旧令牌、打开无 opener 的设置页、真实构建 CSP 下的连接栏与向导识别；GM 仍为模拟，不代替浏览器扩展安装验收。

具体测试数量以运行输出为准。50 MB 本地运行时邮件约 68.4 MB，单个编码块不超过 79,872 字节；这不构成云端速度或 CPU 额度保证。

在线参数核对页另通过 headless Chromium 检查：四项默认明文、逐项显示/隐藏、格式检查、复制和剪贴板拒绝时的手动复制、重新生成令牌的确认、清空和刷新清空；填写与复制不触发网络请求，不写入 localStorage/sessionStorage。检查了 390px 手机布局。此测试不修改 Cloudflare 部署表单，也不验证真实授权码。
