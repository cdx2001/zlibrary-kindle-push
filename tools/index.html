Z-Library → Kindle Push

准备四个值，然后部署。

每一步都注明网页、操作位置和要复制的内容。本页不接收邮箱、授权码或令牌；所有配置填写在你自己的 Cloudflare 服务中。

三个按钮等大，均在新标签页打开。请用 Firefox 操作，安装确认仍需本人点击；已有的步骤可以跳过。

1

生成访问令牌 API_TOKEN

  1. 打开 随机 API_TOKEN 生成器 ↗。
  2. 点击“生成新令牌”→“复制令牌”，把生成的 64 位字符串保存在自己的密码管理器中。
  3. 部署时填入 API_TOKEN；之后浏览器连接服务时使用同一个值。

这个值由你自己生成，不需要在 Cloudflare 账号的 API Tokens 页面申请。

2

找到发件地址 SMTP_USER

  1. 打开 126 邮箱登录页 ↗，登录要用来发信的账号。
  2. 查看邮箱页面显示的当前账号，复制包含 @126.com 的完整邮箱地址；没有账号时先从登录页的“注册新账号”入口注册。
  3. 部署时填入 SMTP_USER。稍后 Amazon 白名单也填写这个地址。

示例格式：你的账号@126.com。这里填地址，不填密码或 Kindle 邮箱。

3

取得邮箱授权码 SMTP_AUTH_CODE

  1. 仍在 126 邮箱 ↗，进入设置 → POP3/SMTP/IMAP。
  2. 开启包含 SMTP 的客户端服务，按提示完成手机或安全验证；如果已经开启，选择“新增授权密码/授权码”。
  3. 复制页面新生成的客户端授权码，私下保存，然后填入 SMTP_AUTH_CODE。授权码通常只展示一次。

不是网页登录密码。SMTP 用户地址与授权码必须属于同一个 126 账号。

网易官方客户端协议开启说明 ↗。设置页面需要登录，不能提供绕过登录的固定授权码链接。

4

找到接收地址 KINDLE_EMAIL

  1. 打开 Amazon 管理内容和设备（美国站）↗。若 Kindle 注册在其他地区，使用对应站点：日本站 ↗ / 英国站 ↗，登录与设备相同的账号。
  2. 选择偏好设置 / Preferences → 个人文档设置 / Personal Document Settings → 发送至 Kindle 电子邮箱设置。
  3. 找到要接收文档的设备或 App，复制它的完整接收邮箱，填入 KINDLE_EMAIL。
  4. 在同页的已认可的发件人电子邮箱列表中添加第 2 步的完整 126 邮箱地址。

Kindle 接收地址不是 Amazon 登录邮箱。建议其 @ 前缀独立、难猜，不照搬发件邮箱；不是禁止所有相同字符，也不保证免于 Amazon 邮件确认。修改接收地址后同步更新 Secret。

地区或界面不同时，可从 Amazon“账号 → 管理您的内容和设备”进入；若网页版找不到，也可在 Kindle 设置中的账号/发送至 Kindle 邮箱查看接收地址。Amazon 邮件发送说明 ↗

把四个值填到 Cloudflare

  1. 点击顶部“部署到 Cloudflare”，按引导登录自己的 Cloudflare 与 GitHub，在四个 Secret 字段填入刚才准备的值。
  2. 若没有四个输入框：打开 Cloudflare 控制台 ↗ → Workers & Pages → 你的 Worker → Settings → Variables and Secrets → Add。类型选 Secret，按名称分别填写四项，再保存并部署。
  3. 若公开仓库导入报“Failed to get repository contents”，返回创建应用页，改用“连接 GitHub / 导入自己账号仓库”，授权并选择 cdx2001/zlibrary-kindle-push、分支 main。构建命令 npm run build，部署命令 npm run deploy。
  4. 部署成功后，在 Worker 概览中的“访问 / Visit”或域名区域找到 https://你的服务.你的子域.workers.dev。这是浏览器脚本要连接的服务网址；不是 GitHub 仓库网址，也不是 Z-Library 网址。

示例只说明格式，不是可用地址。控制台中具体 Worker 的链接包含你的账号信息，需从自己登录后的项目进入。

最后安装并连接

在 Firefox 点顶部另外两个安装按钮并确认。回到 项目仓库 ↗ 刷新，在连接栏填自己的 Worker 网址；或从暴力猴菜单选择“连接或更换自己的 Cloudflare 服务”。

在自己的服务设置页输入同一个 API_TOKEN，点击“验证连接并保存”，再启用书籍站点。此验证只登录 SMTP，不发邮件；电脑和 Android 各配置一次。
